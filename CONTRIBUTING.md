# Contributing

Thanks for your interest in contributing to `codex-video-assistant`.

This project welcomes improvements to agents, skills, documentation, examples, workflow design, aesthetic review methods, and compliance guidance.

## Ways To Contribute

You can contribute:

- New or improved Agent definitions
- New or improved Skill instructions
- Documentation fixes
- Public-safe examples
- Aesthetic scoring improvements
- Compliance checklist improvements
- Workflow diagrams and templates

## Contribution Rules

Do not submit:

- Private user data
- Private messages or account dashboards
- Platform cookies
- Tokens
- API keys
- Credentials
- Secrets
- Unlicensed video, image, BGM, font, icon, sound effect, subtitle, voice, or likeness assets
- Paid course materials or copied scripts
- Claims that bypass platform restrictions
- Fabricated trend data, performance claims, or license conclusions

If a source, license, trend, or material status is unclear, mark it as `pending manual confirmation`.

## Agent Contributions

When contributing an Agent, include:

- Agent name
- Goal
- Use cases
- Inputs
- Outputs
- Workflow
- Files to read
- Files to update
- Risk checks
- Things the Agent must not do
- Collaboration with other Agents

## Skill Contributions

When contributing a Skill, keep it reusable and safe:

- Explain when to use it
- Define required inputs and outputs
- Include compliance checks
- Avoid private project records
- Avoid credentials and account-specific assumptions

## Documentation And Examples

Examples must be public-safe. Use self-made, fictional, or clearly authorized content. Do not include raw task evidence or private production records.

## Pull Request Checklist

Before opening a pull request, check:

- No private data
- No credentials
- No unlicensed assets
- No generated media unless explicitly authorized
- No unsupported legal or platform policy claims
- No copied copyrighted text or scripts
- Documentation is clear and reproducible
