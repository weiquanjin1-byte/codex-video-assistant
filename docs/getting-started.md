# Getting Started

## 1. Understand The Goal

`codex-video-assistant` is a workflow project for training Codex into an AI video editing assistant. It focuses on planning, learning, reviewing, and compliance, not on bypassing platforms or using unauthorized media.

Read these files first:

1. `README.md`
2. `PROJECT.md`
3. `docs/workflow.md`
4. `docs/multi-agent-architecture.md`
5. `docs/compliance.md`

## 2. Choose A Safe Input

Start with one of these:

- A user-provided topic
- A public and properly cited trend observation
- A product or lesson you own
- A fully self-made example

Do not start with private messages, account dashboards, unlicensed videos, unlicensed music, or personal information.

## 3. Pick A Mode

| Mode | Use When | Rule |
|---|---|---|
| Offline mode | You only use user-provided content and local project files | Mark unknown facts and licenses as pending manual confirmation |
| Online mode | You need public source review | Record source URLs, access date, reliability, and license status |

## 4. Run The Workflow

Use the multi-agent order:

1. Trend research
2. Script writing
3. Copywriting
4. Voice selection
5. BGM selection
6. Editing plan
7. Aesthetic review
8. Compliance review

## 5. Save Public-Safe Outputs

Public examples can go in `examples/`.

Private learning evidence, unpublished materials, user data, account data, keys, cookies, tokens, or raw production assets should not be included in a public release.

## 6. Before Publishing A Repository

Check:

- No API keys, tokens, cookies, or account data
- No private evidence records
- No unlicensed videos, images, BGM, fonts, sounds, icons, voice assets, or likenesses
- No fabricated trend data
- No copied scripts, storyboards, or protected text
- No claims that the tool guarantees publishable content
