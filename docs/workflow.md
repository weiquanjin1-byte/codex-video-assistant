# Video Content Workflow

## Overview

This workflow turns a topic or brief into a video production plan. It is designed for short educational, explainer, product, and social videos.

## Workflow Table

| Step | Input | Output | Owner | Risk Gate |
|---|---|---|---|---|
| 1. Topic definition | Topic, platform, audience, duration | Video brief | User or trend agent | Avoid private or unverifiable data |
| 2. Source review | Public or user-provided sources | Source notes | Trend agent | Record source and reliability |
| 3. Script structure | Brief and source notes | Hook, body, ending | Script agent | Avoid false claims |
| 4. Storyboard | Script | Shot list and visual plan | Script/editing agents | Avoid unlicensed materials |
| 5. Copywriting | Brief and script | Title, cover, post copy, tags | Copywriting agent | Avoid misleading claims |
| 6. Voice direction | Script and emotion | Voice type, pace, pauses | Voice agent | Check voice rights |
| 7. BGM direction | Emotion and rhythm | BGM mood, BPM, volume | BGM agent | Check music rights |
| 8. Editing plan | Script, storyboard, voice, BGM | Timeline and production steps | Editing agent | Confirm asset rights |
| 9. Aesthetic review | Draft plan or prototype | Score and improvements | Aesthetic agent | Mark subjective judgments |
| 10. Compliance review | Full package | Final risk report | Compliance agent | Block unsafe items |

## Required Outputs

A complete plan should include:

- Video position
- Target platform and audience
- Core idea
- First 3-second hook
- Script
- Storyboard
- Caption plan
- Voice plan
- BGM direction
- Editing rhythm
- Cover copy and title options
- Aesthetic score
- Compliance checklist

## Production Safety

If an item is not confirmed authorized, mark it as:

`pending manual confirmation`

Do not treat a draft as publishable until the compliance review is complete.
