# Script Example

## Topic

How ordinary people can use AI to improve learning efficiency.

## First 3-Second Hook

AI will not magically make you disciplined, but it can make every study session easier to start.

## 60-Second Script Draft

If you want to use AI for learning, do not start by asking it to "teach me everything."

Start with one clear goal: what do I need to understand in the next 30 minutes?

Then ask AI to explain the topic in three levels: beginner, practical example, and common mistake.

After that, turn the answer into five recall questions. Do not just read the answer. Test yourself.

If you get stuck, ask AI to explain only the part you missed.

At the end, ask it to summarize what you have learned and what you should review tomorrow.

The point is not to let AI replace thinking. The point is to use AI to make thinking easier to organize.

## Caption Style

Short lines, high contrast, one key phrase per screen.

## Risk Notes

- This is a general learning suggestion, not a guaranteed result.
- Do not show real private AI chat records.
