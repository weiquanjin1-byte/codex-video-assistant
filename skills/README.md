# Skills

Skills are reusable instruction files that help Codex repeat project workflows consistently.

## Current Skill

| Skill | Purpose |
|---|---|
| `video-content-workflow/SKILL.md` | Guides video planning, source review, multi-agent execution, aesthetic scoring, and compliance checks. |

## How To Use

1. Read `PROJECT.md` and `README.md`.
2. Read `skills/video-content-workflow/SKILL.md`.
3. Choose a task number and video brief.
4. Follow the multi-agent order in `agents/README.md`.
5. Save public-safe outputs in `examples/` or `docs/`.
6. Keep private evidence, unpublished assets, credentials, and account data out of public releases.

## Public Release Rule

Skill files should describe workflows and safety rules. They should not contain:

- API keys
- Tokens
- Cookies
- Account data
- Private evidence
- Private user information
- Unlicensed media assets
