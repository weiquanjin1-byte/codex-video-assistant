# Video Content Workflow Skill

> task-002 升级说明：本 Skill 的当前有效目标是指导 AI 视频剪辑助手完成视频方案输出、来源审计、审美评分和优化建议。后续如出现重复或旧版描述，以本升级说明和下方新增流程为准。

## task-007 新增：多 Agent 协作模式

当任务涉及完整视频选题、脚本、文案、配音、BGM、剪辑执行、审美复盘或合规检查时，优先按 `agents/README.md` 的多 Agent 顺序执行：

1. `trend-research-agent`：研究公开热点，判断可视频化和风险。
2. `script-writing-agent`：将热点或主题转成视频定位、Hook、60 秒口播稿、分镜和画面建议。
3. `copywriting-agent`：生成标题、封面文案、发布正文、话题标签和评论区引导。
4. `voice-selection-agent`：选择声音类型、语速、情绪、停顿、重音和 TTS/真人口播建议。
5. `bgm-selection-agent`：选择 BGM 情绪、音乐风格、BPM、音量和授权状态。
6. `editing-plan-agent`：生成时间轴、镜头安排、字幕位置、转场、音效点、导出规格和最小成片步骤。
7. `aesthetic-review-agent`：读取 `aesthetic-score.md`，输出评分、扣分原因、最该优化的 3 个问题、是否建议重剪和优化版方案。
8. `compliance-review-agent`：最终检查隐私、版权、抄袭、造假、素材授权、BGM 授权、字体授权、音效授权、肖像权和平台规则风险。

执行规则：

- 每个 Agent 只输出自己职责范围内的内容。
- 前一个 Agent 的输出必须成为后一个 Agent 的输入，并在证据文件中保留链路。
- 任何热点、平台数据、授权素材、授权音乐、授权字体、授权音效和真人声音都必须记录来源和状态。
- 无法访问平台时，`trend-research-agent` 必须说明无法访问，不能伪造热点、热度数据或平台结论。
- 未确认授权的 BGM、素材、字体、音效、图标、声音或肖像不得进入正式制作，只能标记“待人工确认”。
- 所有 Agent 输出必须经过 `compliance-review-agent` 后，才可以进入发布候选方案。

## task-002 新增：视频方案输出流程

每次需要输出视频方案时，按以下顺序执行：

1. 读取 `PROJECT.md`、`CANVAS.md`、`ROADMAP.md`、`CAPABILITY.md`、`SCOREBOARD.md`、`COMPLIANCE.md`、`aesthetic-score.md` 和相关 `learning/` 文件。
2. 确认视频类型：平台、比例、时长、受众、目标、风格、发布限制。
3. 建立文案结构：Hook、背景、核心内容、转折/证明、结尾。
4. 将文案拆成分镜：每个镜头必须对应文案段落、画面内容、镜头类型、时长、素材来源和风险。
5. 设计配音：音色、语速、停顿、情绪、授权边界和是否需要 TTS。
6. 设计字幕：来源、格式、样式、安全区、同步方式和校对方式。
7. 设计剪辑节奏：根据配音长度、信息密度、平台节奏和情绪变化确定切点。
8. 设计音乐音效：只允许使用授权或可合规使用的音乐音效，并记录来源。
9. 输出合规检查：隐私、版权、抄袭、造假、跨项目混用、声音授权。
10. 输出审美评分和优化建议。
11. 保存证据到 `evidence/task-xxx.md`，并更新监管文件。

## task-002 新增：审美评分流程

审美评分必须使用 `aesthetic-score.md`，总分 100 分：

| 维度 | 分值 | 低分信号 |
|---|---:|---|
| 节奏 | 15 | 镜头过长、切点无意义、信息密度失衡 |
| 文案与画面配合 | 15 | 画面没有服务文案，镜头只是堆素材 |
| 画面审美 | 15 | 构图混乱、主体不清、字幕或 UI 遮挡主体 |
| 字幕可读性 | 10 | 不同步、太长、太小、遮挡主体 |
| 配音匹配 | 15 | 音色、语速、停顿、情绪与内容不匹配 |
| 音乐音效 | 10 | 抢话、情绪错误、来源或授权不清 |
| 平台适配 | 10 | 比例、时长、开头节奏不符合目标平台 |
| 合规边界 | 10 | 素材、声音、字体、代码或资料来源不清 |

评分规则：

- 没有脚本、分镜、配音或素材来源时，不得给 90 分以上。
- 没有真实成片或截图时，画面审美只能给方案级判断，必须标记“待实测”。
- 主观审美判断必须写明依据，不能写成绝对事实。
- 评分后必须列出 3-7 条优化建议，并指明对应扣分维度。

## task-002 新增：优化建议输出规则

优化建议必须可执行，避免空泛描述。

| 问题类型 | 建议格式 |
|---|---|
| 节奏问题 | 指出哪个段落过快/过慢，并建议镜头时长或切点调整 |
| 文案画面不匹配 | 指出对应文案和镜头，建议替换画面或重写文案 |
| 配音不匹配 | 指出音色、语速、停顿或情绪问题，给出替代方案 |
| 字幕问题 | 指出位置、长度、字号、同步或安全区问题 |
| 版权问题 | 指出素材/音乐/字体/声音来源缺口，要求替换为授权来源 |
| 造假风险 | 指出未验证结论，要求移入待验证区或补充来源 |

每条优化建议都应包含：问题、影响、修改动作、需要更新的文件或证据。

## 1. Skill 名称

video-content-workflow

## 2. 适用场景

当本项目需要训练或使用 AI 视频剪辑助手能力时使用，包括：

- 自主学习视频剪辑知识
- 查阅和整理公开资料
- 判断资料可靠性、合规性和可用性
- 设计视频制作工作流
- 设计不同视频类型的剪辑方案
- 设计文案、画面、配音、字幕、节奏的配合方案
- 判断节奏、审美、情绪、画面、字幕、配音是否协调
- 输出视频制作方案
- 记录证据、更新能力和合规状态

本 Skill 的目标不是单纯查资料，而是逐步把 Codex 训练成具有审美判断和剪辑方案能力的 AI 视频剪辑助手。

## 4. 如何确定视频类型

先确认以下信息：

| 判断项 | 需要确认 |
|---|---|
| 平台 | 抖音 / 小红书 / B 站 / YouTube / 其他 |
| 比例 | 竖屏 9:16 / 横屏 16:9 / 方形 1:1 |
| 时长 | 15 秒 / 30 秒 / 60 秒 / 长视频 |
| 类型 | 解说 / 口播 / 教程 / 混剪 / 产品展示 / 剧情 / 信息流广告 |
| 目标用户 | 新手 / 专业用户 / 潜在客户 / 粉丝 / 内部团队 |
| 内容目标 | 引流 / 教学 / 转化 / 品牌 / 复盘 / 娱乐 |
| 风格 | 轻松 / 专业 / 情绪化 / 快节奏 / 纪录感 |

无法确认时，在任务证据中标记“待确认”，不要擅自写成事实。

## 5. 如何生成文案结构

文案结构必须先于分镜、配音和剪辑。

推荐结构：

| 部分 | 作用 | 输出 |
|---|---|---|
| Hook | 前 3 秒吸引注意 | 一句话开场 |
| 背景 | 说明问题或场景 | 1-2 句 |
| 核心内容 | 展开观点、步骤或卖点 | 分段脚本 |
| 转折 / 证明 | 增强可信度或情绪 | 案例、对比、结果 |
| 结尾 | 行动引导或总结 | CTA / 总结句 |

文案必须标记目标平台、目标受众、核心观点、事实依据、资料来源、字幕需求和配音需求。

## 6. 如何设计分镜

分镜必须从文案段落生成，不能只堆素材。

| 镜头 | 对应文案 | 画面内容 | 镜头类型 | 时长 | 素材来源 | 情绪 | 风险 |
|---|---|---|---|---|---|---|---|

设计规则：

- 每个镜头必须对应脚本段落或情绪变化。
- 镜头时长应与配音长度匹配。
- 字幕安全区要提前考虑。
- 横屏转竖屏时要确认主体位置。
- 不使用未授权人物肖像、品牌素材、影视片段或平台搬运素材。

## 7. 如何选择配音

配音选择必须确认：

| 项目 | 检查点 |
|---|---|
| 配音类型 | 解说 / 口播 / 情绪配音 / 多角色 |
| 声音来源 | TTS / edge-tts / 授权录音 / 自有声音 |
| 多音色 | 语言、性别、年龄感、风格 |
| 语速 | 是否适合平台节奏 |
| 停顿 | 是否匹配标点、分镜和字幕 |
| 情绪 | 平静 / 兴奋 / 温暖 / 紧张 / 专业 |
| 授权 | 是否允许使用、商用、二次处理 |

禁止使用未授权真人声纹、克隆他人声音、仿冒公众人物或把未确认服务条款的在线 TTS 输出用于正式商用结论。

## 8. 如何匹配剪辑节奏

剪辑节奏由文案、配音、画面和音乐共同决定。

1. 先确定脚本段落。
2. 生成或估算每段配音时长。
3. 把配音时长转换为镜头时长。
4. 根据情绪和平台节奏决定切点密度。
5. 如果有 BGM，标记 beat / 情绪点。
6. 检查字幕是否和配音对齐。
7. 检查画面是否和文案语义对齐。

工具或项目未核验前，只能写“待验证”，不能写成已具备能力。

## 9. 如何生成字幕方案

字幕方案必须说明：

| 项目 | 要求 |
|---|---|
| 字幕来源 | 文案 / 配音 ASR / 手工校对 |
| 格式 | SRT / VTT / ASS / 烧录字幕 |
| 语言 | 中文 / 英文 / 双语 |
| 样式 | 字号、颜色、位置、安全区 |
| 同步方式 | 按配音时间码 / 按脚本估算 / 人工校对 |
| 风险 | 错字、不同步、敏感词、版权文本 |

字幕最好基于最终配音生成或校对，不得让脚本、配音、字幕三者内容不一致。

## 10. 如何检查素材版权

所有素材必须记录来源。

| 素材 | 来源 | 授权 | 是否可商用 | 是否需署名 | 是否可二改 | 风险 |
|---|---|---|---|---|---|---|

License 不明确时，不得进入正式制作方案。

## 11. 如何检查隐私风险

必须检查真实个人信息、私信、聊天记录、账号后台数据、API Key、token、密钥、未授权真人声音、肖像、声纹、跨项目用户数据和未授权素材链接。

发现隐私风险时，不复制原文，只记录风险描述，不进入正式视频方案，并更新 `learning/privacy-audit.md` 和 `COMPLIANCE.md`。

## 12. 如何判断节奏、审美、情绪、画面、字幕、配音是否协调

每个视频方案必须进行协调性检查：

| 维度 | 判断问题 | 结果 |
|---|---|---|
| 节奏 | 镜头长度、切点、信息密度是否适合平台和主题？ | 待填 |
| 审美 | 画面、字体、颜色、排版是否统一？ | 待填 |
| 情绪 | 文案、配音、音乐、画面情绪是否一致？ | 待填 |
| 画面 | 每个镜头是否服务于脚本，而不是堆素材？ | 待填 |
| 字幕 | 字幕是否准确、同步、可读、不遮挡主体？ | 待填 |
| 配音 | 音色、语速、停顿是否符合内容和受众？ | 待填 |
| 合规 | 素材、声音、文字、数据是否可用？ | 待填 |

判断必须区分事实和主观审美。主观判断要写明依据，例如平台风格、案例观察、用户目标或复盘反馈。

## 13. 如何输出最终视频制作方案

最终方案至少包含：

- 视频类型
- 平台和比例
- 目标受众
- 主题
- 文案结构
- 完整脚本或脚本大纲
- 分镜表
- 素材清单
- 配音方案
- 字幕方案
- 剪辑节奏表
- 音乐音效方案
- 协调性检查
- 导出规格
- 发布检查清单
- 来源审计
- 隐私、版权、抄袭、造假风险
- 证据文件位置

如果某项尚未验证，必须写“待验证”，不能写成已完成。

4. 资料是否已经核验？
5. 哪些内容是事实，哪些只是计划或假设？
6. 是否存在隐私、版权、抄袭、造假风险？
7. 输出了哪些视频制作方案内容？
8. 节奏、审美、情绪、画面、字幕、配音是否协调？
9. 更新了哪些监管文件？
10. 证据文件在哪里？
